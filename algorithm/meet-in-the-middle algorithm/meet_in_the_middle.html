> Meet in the Middle

Kỹ thuật chia để trị cho không gian tìm kiếm mũ // demo: Subset Sum

Ý tưởng

Khi n nhỏ (thường ≤ 40) nhưng đủ lớn để duyệt 2^n là bất khả thi, ta chia mảng làm 2 nửa, mỗi nửa có n/2 phần tử. Duyệt toàn bộ 2^(n/2) tập con của từng nửa (rẻ hơn nhiều so với 2^n), rồi ghép kết quả hai nửa lại (thường bằng sort + binary search, hoặc hash set) để suy ra đáp án cho toàn bộ mảng.

Độ phức tạp giảm từ O(2^n) xuống còn O(2^(n/2) · log(2^(n/2))) — ví dụ n = 40: 2^40 ≈ 10^12 (không khả thi) → 2^20 · 20 ≈ 2·10^7 (chạy được).

Demo: Subset Sum bằng Meet in the Middle

Nhập mảng và tổng đích S. Thuật toán sẽ chia mảng làm 2 nửa, sinh tổng mọi tập con mỗi nửa, rồi kiểm tra xem có cặp (tổng nửa trái + tổng nửa phải = S) hay không.

Cài đặt C++

const int N = 40;
int n; long long a[N], S;

void genSums(int l, int r, vector<long long>& res) {
    int len = r - l;
    for (int mask = 0; mask < (1 << len); mask++) {
        long long sum = 0;
        for (int i = 0; i < len; i++)
            if (mask >> i & 1) sum += a[l + i];
        res.push_back(sum);
    }
}

bool solve() {
    int mid = n / 2;
    vector<long long> left, right;
    genSums(0, mid, left);      // 2^(n/2) tập con nửa trái
    genSums(mid, n, right);     // 2^(n-n/2) tập con nửa phải

    sort(right.begin(), right.end());
    for (long long x : left) {
        // cần y = S - x trong nửa phải -> binary search
        if (binary_search(right.begin(), right.end(), S - x))
            return true;
    }
    return false;
}

Biến thể: nếu cần đếm số cặp hoặc k gần nhất thay vì chỉ tồn tại/không, dùng lower_bound/upper_bound trên mảng right đã sort thay vì binary_search.

Khi nào dùng?

• Subset sum / knapsack với n ≤ 40, giá trị lớn (không dùng được DP theo giá trị).
• Đếm số cặp/bộ thỏa điều kiện tổng/XOR trong tập lớn, chia thành 2 tập con độc lập.
• Bài toán mà không gian trạng thái là 2^n nhưng có thể tách thành 2 nửa độc lập rồi ghép bằng sort/hash — ví dụ đếm subset XOR = k, 4-SUM, một số bài Knapsack đếm phương án.
• Điều kiện tiên quyết: phải ghép được kết quả hai nửa hiệu quả (thường O(log) hoặc O(1) mỗi lần), nếu không sẽ mất hết lợi ích.
